Task 10

Write a function for the previous Task, so that you can feed it any vector you like (as argument). Use the standard R function length in the specification of the counter.

scaleFun <- function(x) {
    for (i in 1:length(x)) {
        if (x[i] < 5 | x[i] > 90) 
            x[i] <- x[i] * 5 else x[i] <- x[i] * 0.1
    }

    return(x)
}
